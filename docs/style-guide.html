1. 基本方針

  • CSS フレームワークは使わない。スタイルは React のインライン style（CSSProperties オブジェクト）で書く。
  • 配色は落ち着いた業務画面寄り（AWS コンソール風）。彩度の高い色はアクセント（青）とステータスだけに使う。
  • 文字は小さめ（本文 13px）。情報量を詰めても読めるよう、色の濃淡で階層を出す。
  • UI の文言は日本語。ボタンは何が起きるかが分かる動詞にする（「変更」「削除」「移動する」）。
  • 全体の背景は #f4f5f6、コンテンツは白いカードに載せる。

6. 書き方の決まり

  • スタイルはコンポーネントのファイル末尾に const btn: CSSProperties = {…} の形でまとめる。JSX の中に長い style を直接書かない。
  • 複数の画面で使う値は web/src/lib/style.ts に置く（今は STATUS_COLOR）。色を新しく増やすときは、まずこのガイドの既存色で足りないかを見る。
  • ホバーなどの状態変化は useState で持って style を切り替える（CSS の :hover は使えないため）。
  • 破壊的な操作（削除・ステータス変更・移動）は必ず確認を挟む。文面は「対象」と「起きること」を書く。
  • フォームは Enter で送信（IME 変換中は無視: e.nativeEvent.isComposing）、Escape でキャンセル。失敗したらモーダルは閉じない。
  • 表示の好み（列幅、開閉状態）は localStorage に保存し、読み書きは try/catch で囲む。
  • 日付は toLocaleString("ja-JP")。値が無いときは「—」か「-」で埋め、空欄にしない。
  • 読み込み中は「読み込み中…」、空のときは次の一手を書く（例:「プロジェクトがありません。「新規プロジェクト」から作成してください。」）。
